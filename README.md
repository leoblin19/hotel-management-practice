# Учебный прототип ИС управления гостиницей

Локальная консольная программа на Python и SQLite. Демонстрирует учёт номеров,
поиск доступности, бронирование, заселение, выезд и смену готовности номера.
Реальные данные гостей и внутренние данные гостиницы не используются.

## Запуск

Требуется Python 3.10 или новее. Дополнительные пакеты не нужны.

```text
python hotel.py add-room 101 Стандарт 2
python hotel.py available 2026-07-01 2026-07-04
python hotel.py reserve 1 Гость_1 2026-07-01 2026-07-04
python hotel.py list
python hotel.py checkin 1
python hotel.py checkout 1
python hotel.py room-status 1 ready
```

Файл базы по умолчанию: `hotel_demo.sqlite3`. Другое имя задаётся через
`--db ПУТЬ` перед командой.

Проверка:

```text
python -m unittest discover -s . -p test_hotel.py -v
```

## Границы

Программа предназначена для учебной демонстрации. В ней нет авторизации,
журнала действий, интерфейса для персонала, резервного копирования и интеграций.
Не подключайте её к производственной инфраструктуре и не вводите реальные
персональные данные.
